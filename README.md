# Юрій Танасійчук — автоматизація бізнес-процесів з AI

Допомагаю компаніям позбутися ручної рутини: заявки не губляться, клієнти отримують відповідь за хвилини, дані не переписуються вручну, а керівник бачить цифри без збору звітів.

- Сайт з кейсами: https://ai-expert.com.ua/
- Шукаю постійну роботу в українській компанії, дистанційно

## Що автоматизую

- **Заявки і продажі:** кожна заявка автоматично потрапляє в CRM, менеджер отримує задачу
- **Підтримка клієнтів:** Telegram-боти з базою знань; складні питання — людині
- **Найм і HR:** від заявки керівника до плану першого тижня новачка; AI-розбір резюме
- **Документи:** дані з PDF і заявок потрапляють у систему без ручного переписування
- **Звітність:** щоденний звіт керівнику в Telegram

## Кейси

| Проєкт | Що змінилось для бізнесу | Статус |
|---|---|---|
| Освітня платформа (Softr, Airtable, Make, AI) | Тестування учнів автоматичне, вчитель бачить готові результати | Працює у закордонного клієнта |
| Автоматизація найму в Odoo + Claude API | Кожна передача кандидата — задача з терміном; AI-розбір резюме ≈ $0.03 | Прототип (тестове завдання) |
| Telegram-бот підтримки клієнтів з AI | Звернення має номер, статус і відповідального | Прототип для замовника |
| AvtoAnalituka (Python, Telethon) | Оголошення з Telegram-каналів → база і дашборд цін | Прототип |
| AI-чат по PDF-документах (RAG) | Відповідає тільки з документів і вказує сторінку джерела | Демо, код: [grounded-pdf-chat](https://github.com/YuriiApps/grounded-pdf-chat) |

## Як працюю

Аудит процесу → один процес за 1–2 тижні → порівняння «до / після» → наступний процес.
AI радить, рішення ухвалює людина. Система будується на ваших інструментах і лишається вашою.
